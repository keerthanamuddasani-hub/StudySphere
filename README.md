# StudySphere — Student Command Center

A responsive React study dashboard for planning subjects, tasks, focus sessions, exams, notes, habits, resources, and placement preparation.

## Features

- 15 interactive workspace sections
- Working navigation, search, task completion, add-task modal, and focus timer
- Responsive desktop and mobile layout
- Vite production build ready for Vercel

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
